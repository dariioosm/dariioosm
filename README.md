## Hola, soy Darío Sánchez Martín
Soy desarrollador web junior con formación en Desarrollo de Aplicaciones Web (DAW) y estudiante de Desarrollo de Aplicaciones Multiplataforma (DAM). Vivo en Asturias y me interesa el desarrollo backend y las aplicaciones que ayudan a monitorizar dispositivos y automatizar procesos.
[Simulador IoT](https://openmediavault.tail92a5e5.ts.net:8443/dispositivos)
Desarrollé una aplicación web que simula la monitorización de una cámara frigorífica. Desde el panel se pueden gestionar dispositivos y sensores, configurar umbrales de temperatura y consultar las lecturas recibidas.

Diseñé el modelo de datos en MySQL valida los datos y los guarda asociados a cada sensor. También desplegué la aplicación en mi servidor con Docker Compose.
Tecnologías con las que he trabajado

- Control de versiones y despliegue · Git, GitHub y Docker Compose.
